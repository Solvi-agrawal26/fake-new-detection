How Veritas AI Detects Disinformation

01

Text Sanitization

Strips out extraneous markup, URLs, numbers, and punctuation, normalizing the input text to extract core linguistic structures.

02

TF-IDF Vectorization

Calculates Term Frequency-Inverse Document Frequency scores with unigram and bigram token representations across verified corpora.

03

Statistical Classification

Evaluates n-gram feature weights through our trained machine learning classifier to predict real vs fake probability distributions.

Important Disclaimer

This tool gives a prediction based on a machine learning model and is not a guarantee of truth. Machine learning models assess statistical vocabulary patterns and stylistic cues, but cannot replace independent fact-checking, primary source cross-referencing, and journalistic scrutiny.
